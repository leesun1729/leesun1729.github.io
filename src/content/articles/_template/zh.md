## 代码块

行内代码用反引号：`const x = 1`。

多行代码用三个反引号，**必须标语言**才有语法高亮。不标语言的块会当作纯文本（没有高亮）：

```cpp
// 注释会以斜体灰色显示
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    cout << n * 2 << endl;
    return 0;
}
```

支持的语言：`cpp` `c` `python` `js` `ts` `bash` `json` `yaml` `html` `css` `sql` `go` `rust` 等。
