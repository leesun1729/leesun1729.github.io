复制过的东西，往往在真正需要的时候已经找不到了。系统的剪切板一次只保留一条，而日常写代码、查资料、整理文档时，一段命令、一个链接、一张截图常常要在几个 App 之间来回搬运。Paste 是一个常驻 macOS 菜单栏的剪切板管理器，它把复制过的内容持续记录下来，需要时用一个全局快捷键把面板调到眼前，选中就直接粘贴到光标处。它面向的是长时间在键盘上工作、又不希望为此装一个带浏览器内核的桌面应用的人。

## 能力

- 自动捕获与类型识别。复制文字、代码、链接、邮箱、JSON、色值或图片，都会自动进入历史记录，并归入 Text、Code、URL、Email、JSON、Color、Image 七个分类之一。
- 图片记录。截图或复制的图片会被完整保存，可以在面板里预览，也可以重新粘贴出去。
- 全局呼出。在任意 App 中按下 `Cmd+Shift+V` 弹出快速粘贴面板，`↑↓` 选择，`Enter` 粘贴到光标位置，`Esc` 关闭。
- 收藏与置顶。常用条目可以收藏并钉在列表顶部，不会被后面不断产生的新记录挤走。
- 搜索与筛选。左侧分类栏可以按类型筛选，也可以只看图片；顶部搜索框按关键词过滤。
- 本地存储与容量控制。历史上限可选 500、1,000、2,000、5,000 条，保留时长可选 7、14、30、90 天或永久，超限和过期的条目会自动清理。
- 音效反馈。呼出和粘贴都会播放系统音效，操作有明确回执。
- 双面板同步。主面板和快速粘贴面板共用同一份数据，任一侧的删除、收藏、置顶会立刻反映到另一侧。
- 设置项集中在一处。主题提供 light、dark、system 三档，容量与保留策略在主面板侧边栏的 Settings 中调整。

## 交互模型

主线只有三步：呼出、选择、粘贴。整个过程都在键盘上完成，不会打断当前正在输入的 App。

`Cmd+Shift+V` 通过 CGEvent Tap 在系统层面全局拦截，因此不依赖前台是哪个程序，也不需要先点菜单栏图标。面板以 `NSPanel` 的形式浮在当前窗口之上，`↑↓` 移动选中项，`Enter` 触发粘贴，`Esc` 收起。粘贴本身是 CGEvent 模拟一次 `Cmd+V`，把内容送进当时获得焦点的输入框，所以 Paste 不需要成为前台应用，也不需要用户手动切换窗口。

两个面板的数据来自同一个 Store。主面板是完整视图，可以浏览全部历史、删除、收藏、置顶、改设置；快速粘贴面板是呼出时用的轻量视图，只承担选择和粘贴。两者不是各自持有一份副本，而是读同一份状态，所以在主面板里删掉一条记录，下次呼出时它就已经不在了，不存在需要手动刷新或重新加载的情况。

弹出面板早期在中文输入法下无法输入，后来改成 `KeyablePanel` 才解决。这类细节是原生窗口方案必须自己处理的部分，也是它比套一层 WebView 更费事的地方。

## 技术决策

**纯 SwiftUI，不引入 Electron 或 WebView。** 这是整个项目里影响最大的一次取舍。剪切板管理器本质上是个常驻后台的小工具，如果按 Electron 的路子做，用户就要为一个"复制历史"常年付出几百 MB 内存和一个完整的浏览器运行时。用 SwiftUI 加 AppKit 写，代价是全部 UI 和窗口行为都要自己实现，跨平台的可能性也一并放弃了。换来的是启动快、内存占用与原生应用同量级，以及 `NSPasteboard`、`CGEvent` 这些系统能力可以直连，不必经过任何中间层。

**数据只留在本地，不做云端同步。** 剪切板历史里出现密码、私钥、内部地址是迟早的事，一旦上云，泄露面就不再由用户自己控制。Paste 的选择是把记录写进本地的 UserDefaults 并用 JSON 编解码，配合可配置的容量上限和保留时长来控制体积。代价很直接：换机器或重装系统不会带走历史，多设备之间也没有同步。项目认为对这类数据来说，这个代价是值得的。

**粘贴注入依赖辅助功能权限。** 模拟 `Cmd+V` 属于向其他应用注入键盘事件，macOS 要求进程持有辅助功能权限才能这么做。Paste 无法绕开这一步，只能在首次使用时引导用户到系统设置里授权。副作用是每次重新编译或替换 `Paste.app` 之后授权都会失效，需要重新添加一次；快捷键突然失灵时，第一件要检查的也是这里。

**类型识别采用固定分类，而不是自由标签。** 把记录归入 Text、Code、URL、Email、JSON、Color、Image 这七类，好处是筛选栏的结构稳定，用户扫一眼就知道去哪儿找。代价是分类边界必然有模糊地带，比如一段既是文本又像代码的内容，只能落到其中一类。项目选择接受这种模糊，而不是引入可编辑标签或更复杂的推断，因为后两者会让这个只用来"找东西"的界面变重。

**窗口层用 AppKit，视图层用 SwiftUI。** 菜单栏图标、全局快捷键、浮层面板都需要比 SwiftUI 更细的窗口控制，所以这部分交给 `AppDelegate` 和 `NSWindow` / `NSPanel` 处理，界面内容仍由 SwiftUI 渲染。

## 安装与要求

需要 macOS 14 或更高版本。

从 [Releases](https://github.com/leesun1729/Paste/releases/latest) 下载最新的 `Paste.dmg`，打开后把应用拖进 `/Applications/`。

首次运行需要授予辅助功能权限：打开 **系统设置 → 隐私与安全性 → 辅助功能**，点 `+`，选择 `/Applications/Paste.app`。没有这一步，`Cmd+Shift+V` 可以呼出面板，但粘贴不会生效。

如果更愿意自己编译，需要先装 Xcode Command Line Tools（`xcode-select --install`），然后克隆仓库、执行打包脚本，再把产物拷进 Applications：

```bash
git clone https://github.com/leesun1729/Paste.git
cd Paste
./package.sh
cp -R Paste.app /Applications/
```

自己编译出的包同样需要走一遍辅助功能授权。卸载就是删掉 `/Applications/Paste.app`。
